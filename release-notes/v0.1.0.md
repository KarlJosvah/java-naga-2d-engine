# Naga 2D Engine v0.1.0 Release Notes

Welcome to the initial release of **Java Naga 2D Engine (v0.1.0)**! This release establishes the modular engine core, state management pipeline, and an interactive demo application.

---

## 🌟 What's Included

### 🛠️ Core Engine Architecture (`naga-engine.jar`)
* **Modular Application Entry Point (`engine.Main`)**: Hardware-accelerated Swing frame setup with dynamic reflection discovery for application initialization (`App.init()`).
* **High-Precision Game Loop (`engine.GameLoop`)**: Decoupled TPS (Ticks Per Second) logic update and FPS rendering loop with nanosecond timing and CPU-friendly park/spin waits.
* **State Management Pipeline (`engine.gamestate`)**:
  * `GameStateHandler`: Central state stack supporting dynamic state registration (`registerState`), default state configuration (`setDefaultStateID`), and state transitions (`changeState`).
  * `GameState`: Abstract base class providing lifecycle callbacks (`init`, `tick`, `render`, `closeState`), key/mouse input abstraction, and gradient mouse hover utilities.
  * `InputEvent` & `StateID`: Abstracted input queue pipeline and type-safe state identifiers.
* **Utilities Suite (`engine.tools`)**:
  * `AssetsLoader`: Asset loading helper for TrueType fonts, WAV audio clips, and images.
  * `Function`: Full-screen exclusive mode, screen resolution detection, and color hex utilities.

### 🎮 Demo Application
* **Entry Configuration (`App.java`)**: Configures default state initialization (`MenuState.ID`).
* **Main Menu (`demo.MenuState`)**: Interactive menu with option selection, audio sound effects, and state switching.
* **Physics & Gameplay Demo (`demo.DemoState`)**:
  * Player physics and movement (`Player.java`).
  * Collision geometry (`StaticBody.java`, `CollisionShape.java`, `Rectangle.java`).
  * Smooth target-following camera (`Camera.java`).
  * Particle / projectile system (`Bullet.java`) and tilemap rendering (`Map.java`).

### 📦 Build & CI/CD Pipeline
* **Local Build Automation (`.vscode/run.bat`)**: Automated script compiling `src/engine` into `lib/naga-engine.jar` and building external projects cleanly.
* **Automated GitHub Releases Workflow (`.github/workflows/release.yml`)**: Builds and attaches `naga-engine.jar` and `naga-demo-bundle.zip` on tag releases.
