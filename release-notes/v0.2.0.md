# Naga 2D Engine v0.2.0 Release Notes

Version **v0.2.0** marks a major architectural milestone for the engine: the introduction of **`StateElement`** and a component-driven composition model within `GameState`.

---

## 🌟 The Big Shift: Component-Driven `StateElement` Architecture

Previously, a `GameState` was responsible for manually holding, ticking, rendering, and routing input to every sub-system and entity. In **v0.2.0**, `GameState` evolves into a composite container that manages lightweight, lifecycle-aware components implementing **`StateElement`**.

### 🧩 `StateElement` Interface (`engine.gamestate.StateElement`)
Provides a complete component lifecycle contract where all methods have `default` implementations, allowing entities to implement only what they need:
* `init(GameState parentState)` — Hook called when the component is registered or when the parent state initializes.
* `tick(double elapsedSecond, long loopID)` — Component-specific logic update.
* `render(Graphics2D g, int renderWidth, int renderHeight)` — Rendering hook.
* `input(InputEvent event)` — Direct input handling hook (automatically skipped if the event was already consumed).
* `close()` — Component cleanup hook.

### 🎮 Enhanced `GameState` Lifecycle Management
* **Dynamic Element Registry**: `addElement(element)`, `removeElement(element)`, and `clearElements()`.
* **Automatic Lifecycle Synchronization**: Adding an element to an already-active state immediately triggers `init(this)`. Transitioning away from a state automatically calls `close()` on all elements.
* **Declarative Dispatch Helpers**: Built-in `tickElements(elapsedSecond, loopID)` and `renderElements(g, renderWidth, renderHeight)` eliminate repetitive loop boilerplate.
* **Non-Breaking & Backwards-Compatible**: Existing states can continue using custom monolithic update loops or adopt `StateElement` components incrementally.

## 🐍 New Showcase: Modular Snake Implementation (`demoelement`)

To demonstrate the power and clarity of `StateElement`, the repository now includes a fully decoupled Snake implementation under `src/demoelement`:

* **`SnakeState` (`demoelement.SnakeState`)**: A concise, declarative state that registers and coordinates components.
* **Separated Entity Components (`demoelement.entity.*`)**:
  * **`Grid`**: Manages responsive board layout and grid line rendering.
  * **`Food`**: Handles random positioning, empty-cell respawning, and food rendering.
  * **`Snake`**: Encapsulates movement timing, body segments, collision rules, and player inputs.
  * **`SnakeHud`**: Handles score overlays, pause screens, and game-over banners.
* **Layout & Geometry Utilities (`demoelement.core.*`)**:
  * `BoardContext`: Viewport-adaptive scaling and coordinate conversions.
  * `Cell` & `Direction`: Immutable position and directional math.
