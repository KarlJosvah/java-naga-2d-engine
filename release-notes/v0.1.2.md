# Naga 2D Engine v0.1.2 Release Notes

Version **v0.1.2** introduces built-in mouse button constants on `InputEvent` to simplify input handling, eager static font preloading in `AssetsLoader`, and updates to the demo application to use these new conveniences.

---

## 🚀 What's New in v0.1.2

### 🖱️ Mouse Button Constants (`engine.gamestate.InputEvent`)
* Added mouse button constants directly to `InputEvent` so client code no longer needs to import `java.awt.event.MouseEvent` for checking button codes:
  * `InputEvent.NONE` (`MouseEvent.NOBUTTON`)
  * `InputEvent.BUTTON1` / `InputEvent.LEFT`
  * `InputEvent.BUTTON2` / `InputEvent.MIDDLE`
  * `InputEvent.BUTTON3` / `InputEvent.RIGHT`

### 🔤 Eager Static Font Loading (`engine.tools.AssetsLoader`)
* **Preloaded Font Asset**: Added `public static Font font_android_101` in `AssetsLoader`, eagerly loaded via a static initializer block from `Android 101.ttf`.
* **Simplified Game & Engine Usage**:
  * `GameLoop.java`: FPS counter now derives its font directly from `AssetsLoader.font_android_101`.
  * `MenuState.java`: Menu options now derive their display font from `AssetsLoader.font_android_101`, removing duplicate load logic.
