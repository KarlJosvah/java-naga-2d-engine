# Naga 2D Engine v0.1.1 Release Notes

Version **v0.1.1** introduces new runtime configuration options for the game loop target frame rate, default background color customization, and vertical sync (VSync) toggle management.

---

## 🚀 What's New in v0.1.1

### 🎮 Game Loop & Rendering Customization (`engine.GameLoop`)
* **Target FPS Management**: Added `GameLoop.setTargetFPS(int targetFPS)` and `GameLoop.getTargetFPS()` to dynamically set and query target rendering frame rates (enforces a minimum bound of 20 FPS).
* **Default Background Color Customization**: Added `GameLoop.setDefaultBackgroundColor(Color bg)` and `GameLoop.getDefaultBackgroundColor()` methods to allow customizable background canvas clear colors.

### ⚙️ Engine Frame & VSync Controls (`engine.Main`)
* **VSync Toggle Support**: Added `Main.VSYNC(boolean activate)` and `Main.VSYNC()` methods to enable or disable vertical synchronization programmatically before frame creation.
* **Conditional Buffer Strategy**: Configured frame initialization to conditionally select unsynced hardware buffer strategy (`createUnsyncedBufferStrategy()`) when VSync is enabled, falling back to standard triple buffering (`createBufferStrategy(3)`) when disabled.
